# Тема проекта: "Генератор паролей"  

_Система позволяет генерировать пароли различной длины, используя различные опции для их генерации. 
Система хранит пароли в зашифрованном виде (с возможной вариацией выбора для пользователя), а также хранит историю их формирования._  

## Технологический стек:

* **Язык программирования:** Java 21
* **Фреймворки:** Spring Boot 3.5.5 (Web, Security, Data JPA, Thymeleaf, Actuator, Validation)
* **База данных:** PostgreSQL 17
* **Тестирование:** JUnit 5
* **Сборщик и контейнеризация:** Maven, Docker, Docker Compose

---
## Запуск проекта

### Запуск через Docker Compose:

В корневой директории проекта выполнить команду:
```bash
docker compose up
```

### Конфигурация и переменные окружения

Приложение использует следующие переменные среды для подключения к базе данных (заданы по умолчанию в `docker-compose.yml`):

| Переменная    | Описание                     | Значение по умолчанию                  |
|:--------------|:-----------------------------|:---------------------------------------|
| `DB_URL`      | URL подключения к PostgreSQL | `jdbc:postgresql://db:5432/naujava_db` |
| `DB_USERNAME` | Имя пользователя БД          | `nau_user`                             |
| `DB_PASSWORD` | Пароль пользователя БД       | `nau_password`                         |

## Вход в систему

Для входа в систему добавлен sql-скрипт инициализации для роли администратора. 
Чтобы его отключить необходимо перейти в `application.yml` и поменять опцию типа запуска скрипта c:
```yaml
  sql:
    init:
      data-locations: classpath:sql/init.sql
      mode: always
```
на:
```yaml
  sql:
    init:
      data-locations: classpath:sql/init.sql
      mode: never
```
